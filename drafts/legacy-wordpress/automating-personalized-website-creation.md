WebSPL is a prototype tool that applies software product line engineering to website generation. Instead of building sites manually, users select features through a configuration interface, and WebSPL automatically assembles a valid, fully functional website from plugins, themes, and content — no manual coding required.

The core idea is to treat a family of websites as a product line, where a single feature model captures all possible configurations and an analysis engine ensures only valid ones are generated.

This was my Bachelor’s thesis at Universidad de Sevilla, awarded Honors Distinction in 2022.

*[(link to the public repository in GitHub)](https://github.com/diverso-lab/webspl)*
